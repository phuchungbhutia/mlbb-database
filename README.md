A machine-readable, version-controlled repository containing comprehensive MLBB heroes, equipment, emblems, battle spells, and mathematical synergies. Built for AI/RAG systems, web applications, draft assistants, and analytical research.

---

## 📂 Repository Contents

* **`MLBB_Hero_Database.md`**: Master hero index, skill mechanics, builds, draft priorities, and matchups.
* **`MLBB_Game_Data.md`**: Core item numbers, passive triggers, emblem trees, battle spells, and patch changes.
* **`data/`**: Deterministic JSON files generated directly from markdown tables for programmatic consumption.
