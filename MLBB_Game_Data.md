# Equipment Effects

## Physical Penetration

Reduces the effective physical defense used against physical damage.

Best against:

- Armor stacking
- Frontliners
- Physical defense builds

---

## Magic Penetration

Reduces effective magic defense.

Best against:

- Magic defense items
- Durable magic targets
- High-MR compositions

---

## Anti-Heal

Reduces the effectiveness of enemy healing or regeneration.

Useful against:

- Thamuz
- Uranus
- Ruby
- Estes
- Alpha
- Lifesteal-heavy marksmen
- Regeneration-based tanks

---

## Anti-HP

Deals damage based partly on target HP.

Useful against:

- Tanks
- HP-stack builds
- High-health fighters

---

## Attack Speed

Increases Basic Attack frequency.

Strong with:

- On-hit heroes
- Basic Attack passives
- Golden Staff
- Demon Hunter Sword
- Corrosion Scythe

---

## Cooldown Reduction

Allows abilities to be used more frequently.

Strong with:

- Skill-spam heroes
- Supports
- Mages
- Fighters dependent on repeated rotations

---

## Healing Amplification

Improves applicable healing effects.

Strong with:

- Sustain fighters
- Regeneration tanks
- Healing supports

---

## Movement Speed

Improves:

- Chase
- Escape
- Positioning
- Kiting
- Rotation
- Skill targeting

# Original Server vs Advance Server

## Original Server

Live ranked data.

Use for:

* Current builds
* Current statistics
* Current counters
* Current item effects
* Current hero mechanics

## Advance Server

Experimental data only.

Never treat Advance Server changes as live.

```text
ADVANCE SERVER ≠ LIVE SERVER
```

# Data Quality Rules

1. Never invent statistics.
2. Never invent skill scaling.
3. Never invent item effects.
4. Never mix server versions.
5. Never use outdated item values as current.
6. Separate Ranked and Brawl values.
7. Record the patch for patch-sensitive information.
8. Record source information.
9. Prefer official patch notes for balance changes.
10. Cross-check important mechanics.
